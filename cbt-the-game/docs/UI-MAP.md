### 화면 = PlayScreen, 세 구역

```
┌──────────────────────────── 상태바 (topbar) ────────────────────────────┐
│ DAY n · 생각하는 힘 ● n · 실천 n/6 · 과몰입 n/6                           │
├───────────────────────────────┬─────────────────────────────────────────┤
│  메인 보드 (board-main)        │  카드 시장 (market) — 펼침 영역          │
│  좌중단. 위→아래 3행:          │  우측. 위/아래 2단 가로 스크롤:          │
│   ① 과몰입행동 트랙 (검정)     │   · 펼쳐진 실천카드 (action-strip)       │
│   ② 실천 트랙 (파랑)           │   ·········· 점선 구분 ··········         │
│   ③ 생각 트랙 (초록)           │   · 펼쳐진 생각카드 (thought-strip)      │
│                                │  상단에 "지금 다스릴 충동" 핀(pin)        │
├───────────────────────────────┴─────────────────────────────────────────┤
│  딜 영역 (deal-area) — 하단 전체 폭                                       │
│  [내 덱 deck-pile] [버린 카드 used-pile] → DEAL → [오늘 딜된 카드 줄]     │
│  턴(하루) 시작 시 한 장씩 날아와 펼쳐짐(deal-fly-in). 카드 크기 유지.     │
└──────────────────────────────────────────────────────────────────────────┘
```

### 구역별 호칭

| 호칭 | 위치 | 내용 |
|------|------|------|
| **상태바 (topbar)** | 최상단 | DAY · 생각하는 힘 · 실천/과몰입 요약 |
| **메인 보드 (board-main)** | 좌중단 | 3행 트랙 (아래) |
| · 과몰입행동 트랙 (overuse-track) | 보드 1행 | 충동을 못 막으면 칸이 참. 6칸 = 패배. 검정 |
| · 실천 트랙 (action-track) | 보드 2행 | 형성된 실천카드. 6칸 = 승리. 파랑 |
| · 생각 트랙 (thought-track) | 보드 3행 | 보드에 올린 생각카드 누적(유형별 2장 → 실천). 초록 |
| **카드 시장 (market)** | 우측 | 펼쳐진 구매·사용 가능 카드 |
| · 실천 스트립 (action-strip) | 시장 상단 | 펼쳐진 실천카드, 가로 스크롤 |
| · 생각 스트립 (thought-strip) | 시장 하단 | 펼쳐진 생각카드, 가로 스크롤 |
| · 충동 핀 (impulse-pin) | 시장 머리 | 지금 집은 충동을 고정 표시(정답 표시 X) |
| **딜 영역 (deal-area)** | 하단 전체 폭 | 덱·버린덱·딜 줄 |
| · 내 덱 (deck-pile) | 딜 영역 좌 | 뽑을 카드 더미(뒷면) |
| · 버린 카드 (used-pile) | 딜 영역 좌 | 쓴/버린 카드 더미 |
| · 딜 줄 (dealt-row) | 딜 영역 우 | 오늘 딜된 카드들(충동·생각하는 힘) |

### 카드 색 (캐넌 기본)

| 카드 | 색 | 토큰 |
|------|-----|------|
| 충동카드 | **빨강** | `--impulse` |
| 생각카드 | 초록 | `--thought` |
| 실천카드 | 파랑 | `--action` |
| 과몰입행동카드 | 블랙 | `--overuse` |
| 생각하는 힘(코인) | 앰버 | `--coin` |

### 핵심 동작

- **딜 (deal)**: 하루 시작 → 덱에서 카드가 한 장씩 딜 줄로 날아와 펼쳐짐(stagger fly-in). 카드 크기 유지.
- **집기 (focus)**: 딜 줄의 충동을 클릭 → 충동 핀에 고정. 그 충동을 읽고 시장에서 맞는 생각을 직접 고른다.
- **올리기 (place)**: 시장의 생각/실천 카드를 골라 보드로 올림 → 트랙 채움. "위로 간다"는 물성.
- **마감 (resolve)**: 하루 마치기 → 못 막은 충동은 과몰입행동 트랙으로.

### 미확정 메카닉 (피터공 확인 필요 — 6/23)

> 스케치가 함의하나 캐넌·현재 store와 다를 수 있는 지점. 추측으로 구현하지 않고 여기 모아 확정 후 반영.

1. **생각카드 사용 후 행방** — 스케치 "다시 사용덱으로"(used-pile)로 표시. 피터공 메모는 "쓰면 다시 나의 덱으로 들어가지만(아마, 확인 필요)". → 버린덱 복귀 vs 내 덱 복귀 vs 소멸? 현재 store = 코인 소비식(생각카드는 상점 개념). **확정 필요.**
2. **실천카드 획득·영속** — 스케치: 실천은 한 번 획득하면 계속 사용 가능 + 우측에 펼쳐져 browse. 현재 store: 생각 2장 모이면 자동 형성(별도 구매 아님). → 실천을 browse·획득하는 카드로 둘지, 형성 결과로 둘지. **확정 필요.**
3. **과몰입행동카드 발동 용법** — "충동을 해결 못한 경우 트리거". 현재 store: 마감 시 남은 충동 = 과몰입 트랙 +1(증식 비활성). 정확한 발동·효과 **확정 필요.**
4. **딜 선택 장수** — "처음에는 3~5개까지 선택 가능". 현재 DRAW_START=4, DRAW_MAX=7. 매칭 확인.
