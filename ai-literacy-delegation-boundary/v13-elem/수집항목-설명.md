# AI 리터러시 게임 — 수집 항목 설명

작성: 2026-08-04 (놀공) · 대상 빌드: 중등 `v1.3-mid-r40` / 초등 `v1.3-elem-r40`

이 문서는 게임이 **무엇을 수집하고 무엇을 수집하지 않는지**를 학교·교육청에 설명하기 위한 것이다. 아래 목록이 전부이며, 여기 없는 것은 수집하지 않는다.

---

## 1. 한 줄 요약

**개인을 식별할 수 있는 정보는 하나도 수집하지 않는다.** 수집하는 것은 "이 판에서 어떤 선택을 했고 결과가 어땠는가"뿐이고, 그 판이 누구의 것인지는 우리도 알 수 없다.

## 2. 수집하지 않는 것 (명시)

- 이름, 학번, 학교명, 학급, 교사명
- 이메일, 전화번호, 생년월일, 성별, 나이
- IP 주소 (서버가 요청 IP를 기록에 남기지 않는다)
- 위치 정보, 기기 식별자, 브라우저 지문
- 학생이 입력한 자유 텍스트 (게임에 자유 입력란이 없다)
- 쿠키를 이용한 추적

## 3. 수집하는 것

한 학기(게임 한 판)가 끝날 때까지 아래 항목이 하나의 기록으로 묶인다. 기록 하나의 크기는 1~2KB 정도다.

| 항목 | 내용 | 예 |
|---|---|---|
| 판 식별값 | 판을 묶기 위해 브라우저가 그때그때 만드는 무작위 문자열. **사람과 연결되지 않는다.** | `p_l9x2k7` |
| 빌드 버전 | 어느 버전으로 플레이했는지 | `v1.3-mid-r40` |
| 시작·종료 시각 | 판을 시작하고 마지막으로 진행한 시각 | 2026-09-01 10:12 |
| 완주 여부 | 5개 시나리오를 다 했는지 | 예 / 아니오 |
| 시나리오별 선택 | 1차 선택·2차 선택·검토 선택의 **선택지 번호** | `B` / `B2` / `R3` |
| 시나리오별 결과 | 등급, 점수, 두 역량(위임 판단·아는 것) 변화량, 소비한 시간·에너지 | A / 88점 |
| 시나리오별 소요 시간 | 그 시나리오에 몇 초 걸렸는지 | 212초 |
| 재도전 기록 | 몇 번 다시 했는지, 시도마다 등급이 어떻게 바뀌었는지 | 2회 / D → B |
| 중단 지점 | 중간에 그만뒀다면 어느 시나리오의 어느 단계였는지 | 진로 시나리오, 2차 선택 |
| 학기 종합 | 총점, 최종 레벨, 학습자 유형(6종 중 하나), 획득한 역량 카드 목록 | 441점 / 레벨 3 |

## 4. 왜 이것을 수집하는가

수업 운영과 콘텐츠 개선을 위한 것이고, 학생 개인의 평가에는 쓸 수 없다(누구인지 모르기 때문이다).

- **소요 시간** — 한 차시에 시나리오 몇 개가 들어가는지 정해 교사에게 운영 지침을 준다.
- **중단 지점** — 아이들이 어디서 막히는지 찾아 그 대목의 글과 선택지를 고친다.
- **재도전 등급 변화** — 다시 해서 나아지는지, 즉 이 게임이 실제로 배움으로 이어지는지 확인한다.
- **선택 분포** — 특정 선택지가 아무도 안 고르거나 몰리면 설계를 조정한다.

## 5. 어떻게 저장되는가

- 플레이 중에는 **학생 브라우저 안에만** 쌓인다. 네트워크가 끊겨도 게임은 정상 진행되고, 연결되면 그때 전송한다.
- 전송된 기록은 놀공이 관리하는 AWS 서울 리전의 비공개 저장소에 암호화되어 보관된다. 외부에 공개되지 않는다.
- 같은 판은 계속 덮어써서 하나로 유지된다 — 한 명이 여러 기록으로 늘어나지 않는다.
- 수집 서버는 **정해둔 학교 배포 주소에서 온 요청만** 받는다.

## 6. 열람·삭제

기록에 개인 식별자가 없어 특정 학생의 기록을 찾아내는 것은 기술적으로 불가능하다. 학교나 교육청이 특정 기간·특정 배포분 전체의 삭제를 요청하면 해당 범위를 통째로 삭제할 수 있다.
