## Manifestia 1단계 매칭 테스트 정답지

> 게임에서 캐릭터를 고르고 포스터 번호를 입력해 아래 기대값과 대조한다. (접속 주소는 장소·와이파이마다 바뀌므로 아리공이 그때그때 안내)
> - **완전 매칭(4★)**: 그 포스터 4단어를 전부 받는다. 정답이 정확히 정해짐.
> - **부분 매칭(1~3★)**: 4슬롯 중 **랜덤 1개**만 받는다. 어느 단어인지는 매번 달라서 개수(1개)만 확인. 이미 가진 단어는 재입력해도 안 줌.
> - 새 단어를 받을 때마다 점수 +5.

#### 치유자(HEALER)로 플레이
완전 매칭 — 4단어 전부:
- `52003` 요한 볼프강 폰 괴테 → 괴로움 · 남기다 · 고난 · 까꿍
- `60423` 요한 볼프강 폰 괴테 → 할 수 있다 · 시작 · 개이득 · 후후
부분 매칭 — 4개 중 랜덤 1개:
- `36853` 빅토르 위고 (2★) → 후보: 예술 · 아름다움 · 진보 · 우당탕
- `58543` 알렉산드르 솔제니친 (1★) → 후보: 따라서 · 정부 · 위대한 · 멍멍

#### 공통 케이스
- 없는 번호(예 `00000`) → 찾을 수 없음 안내, 점수 변화 없음
- 완전매칭 포스터를 한 번 더 입력 → 이미 4단어 다 가져서 새 단어 없음
- 부분매칭 포스터를 여러 번 입력 → 안 가진 단어 중 하나씩, 다 모으면 새 단어 없음
