#### 무엇을 만드나

슈테델 KI 디지털 페스티벌(2026-09-04~05 프랑크푸르트) 현장 게임. 포스터에서 단어를 수집해 매니페스토를 조립하고 투표로 겨룬다. 기존에 여러 기기로 나누던 걸 플레이어 폰 하나로 통합, 풀스택 웹앱.

#### 단계적 빌드

- **1단계 — 폰 단독 (현재)**: 게임 루프 3화면(매칭→조립→투표)이 한 폰에서. 서버 없음, 투표 로컬 더미.
- **2단계 — 서버 + 세션 코드 + QR + 멀티플레이**: 세션 코드(시간 모드·캐릭터 배정 방식 파라미터) + 프리필 QR + 실시간 투표.
- **3단계 — 언어 빌드 + 디스플레이 모듈**: 시트 기반 다국어 주입(독>영>한), 운영 시나리오별 공용 화면.

#### 현 상태 (6/22)

- 프레임워크 셋업 + 2화면(캐릭터·매칭) 구현됨(6/18). 디자인 단계 완료: 원형 아트워즈 UI 레퍼런스 카탈로깅 + 결정 4건 + 와이어프레임 7장 → 클로드디자인 보드(claude.ai/design). 피터공 피드백 반영(페이퍼로지·백색·카드 이미지·언어 토글).
- **다음(내일 착수)**: 1단계 코드 빌드 v1 — `SPEC-screens.md` 명세대로 디자인 토큰 + 5화면 신설/채움 + 언어 토글. 순서: `TASKS.md` "1단계 코드 빌드 v1" 13단계.
- 문서: 게임 로직 `SPEC-prototype.md` / 화면 구현 `SPEC-screens.md` / 원형 레퍼런스 `REF-artworz-original-UI.md` / 아키텍처 `ARCHITECTURE.md` / 와이어프레임 `wireframes/`.
- 서버 데이터 모델은 2단계 사안, 별도 논의 대기(1단계와 독립).

#### 핵심 결정 (요약, 상세는 요청 노트)

- 한국어 1차 + UI 텍스트 i18n 시트 분리
- 매칭: 4★=4개 전부 / 1~3★=랜덤 1개
- 단어 소모성 / 복수 소지 X / 재입력 무제한·없는 단어만 복구 / 선물 후순위
- 캐릭터: 1단계 자유 선택 (진단형·팀 할당은 2단계 세션 옵션)
- 데이터: 120 포스터, 480 단어 전부 고유
- 다국어: 독/영/한 런타임 전환. 슈테델 운영 배포는 독/영만(한국어는 개발·테스트용). 우선순위 독>영>한. 시작 화면 DE·EN·KO 토글. (6/22)
