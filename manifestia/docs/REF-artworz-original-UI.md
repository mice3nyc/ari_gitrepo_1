## Manifestia — 아트워즈 원형 UI 레퍼런스 컨택트시트

> Manifestia(슈테델)의 뿌리인 ACC 아트워즈(2018~2019) 현장 게임의 실제 UI 캡쳐를 한자리에 모으고, 우리 1단계 7화면에 매핑했다.
> 출처: `Assets/incoming/Manifesto Game/` (UI original 22장 + img 캐릭터 자산 21장 + 운영매뉴얼 PDF + 최종시나리오 txt)
> 아키텍처: [[ARCHITECTURE]] / 명세: `docs/SPEC-prototype.md`

#### 가장 큰 발견 — 디자인을 새로 발명할 필요가 없다

원형 아트워즈는 우리가 1단계에서 비워 둔 화면(매니페스토 쓰기·투표·결과)뿐 아니라, 피터공이 지금 새로 만들려는 **세션 관리자 기능까지 이미 완성된 디자인으로 존재**한다. 관리자 암호 → 서버/세션 선택(시각·인원수별 목록) → 교환소·투표관련·프린터 3탭. 즉 우리 작업은 "맨땅에서 설계"가 아니라 "검증된 원형을 폰 단독 + 슈테델용으로 옮기기"가 된다.

또 하나, 원형의 디자인 언어가 또렷하다. **평상 화면은 무채색(회색 배경 + 굵은 검은 테두리), 완료·확인 순간에만 노란 배경 + 월계관 일러스트가 터진다.** "평상=무채색 / 완료=노란 폭발"의 이분 리듬. 우리 B&W 하우스 톤과 결이 같고, 포인트 컬러 한 점만 더한 구조다.

---

### 공통 — 진입 (NFC 팀 ID 태그)

원형은 교환소·문장제출·투표소 진입이 모두 같은 화면이다: "자신의 팀 ID카드를 태그해주세요" + 목걸이 ID카드 아이콘. 폰 단독으로 옮기면 NFC 태그가 세션 코드/QR 진입으로 바뀌는 자리다.

### 1. 시작 / 캐릭터 선택

원형엔 타이틀 화면과 4직업 카드 자산이 따로 있다. 우리 ①캐릭터 선택의 설계 근거. (아래 캐릭터 자산은 옵시디언에서 렌더된다 — 백도 API로는 고해상도라 못 읽었지만 파일은 정상.)

### 2. 포스터 매칭 → 단어 획득

**교환소3** — 포스터 인용구("슬픔과 고통을 거쳐야 예술이 된다 -피카소")를 보여주고, 월계관 안 점수 + "2개 일치! 최초발견!" + "단어 선택 하기". 우리 ②포스터 매칭의 결과 화면에 해당. 완료 순간이라 노란/빨강 컬러가 터진다.

![[교환소3.png|360]]

---

### 3. 단어주머니 (인벤토리) — 선택·발급·보유

원형은 단어를 고르고(교환소4) → 발급 완료(교환소5) → 인벤토리 그리드에서 다시 꺼내 쓰는(문장제출2) 3단 구조가 이미 있다. 우리 ④단어주머니의 직접 원형.

![[교환소4.png|300]] ![[교환소5.png|300]]

### 4. 매니페스토 쓰기 (선언 문장)

원형의 "선언 문장 입력"이 곧 우리 ⑤매니페스토 쓰기. 단어 인벤토리에서 고르기(문장제출2) → 문장 직접 입력 + 포함 단어 태그(문장제출3) → 등록 완료 카드(문장제출4, 노란 폭발).

![[문장제출2.png|300]] ![[문장제출3.png|300]]

![[문장제출4.png|360]]

### 5. 투표

진입(투표소1, 위 공통 화면과 동일) → 두 문장 중 하나 선택(투표소2) → 투표 완료 카드(투표소3, 노란 폭발). 우리 ⑥투표.

![[투표소2.png|300]] ![[투표소3.png|300]]

### 6. 결과

원형은 두 페이지로 나뉜다: 선언별 득표 순위(1~6위, 상위 강조) + 문장제출수 시계열 꺾은선 그래프(팀 색상 범례). 우리 ⑦결과.

### ★ 관리자 / 세션 운영 — 우리가 새로 만들려던 것의 원형

피터공이 말한 "세션관련 관리자 기능"이 여기 다 있다.

- **관리자 암호** — 검은 배경 + "관리자 암호를 입력하세요" + 4칸 핀 + 키패드. 운영자 진입 잠금.
- **서버/세션 선택**(교환소1 copy) — "3/10 3:00 시작, Player 60명 / 3/10 2:19 시작, 39명 …" 시각·인원수별 세션 목록에서 현재 세션 선택. **바로 세션 관리의 원형.**
- **교환소 탭**(관리자화면 copy) — 팀별 단어 수령 현황 결산.
- **투표관련 탭**(copy 6) — 투표용 문장 등록·수정.
- **프린터 탭**(copy 7) — 팀 선택해 선언 문장 출력.

### 원형에만 있던 것 — 교환소(단어 교환)

원형은 별도 "교환소" 키오스크에서 아이템 코드를 입력해 단어를 교환했다(교환소1 태그 → 교환소2 코드 입력). 우리 1단계는 이 교환 기능을 v1 제외(단어 480개 전부 고유라 나중 가치)로 두고, 포스터 매칭 + 인벤토리에 흡수했다. 2단계 이후 참고용.

![[교환소2.png|360]]

### 읽지 못한 2장 (옵시디언에서는 보임)

고해상도라 백도 API로는 못 읽었지만 파일은 정상이고 옵시디언에서 렌더된다.

- **전체Display** — 공용 대형 디스플레이용 화면으로 추정(LED wall 모듈 참고).
- **에러팝업 예시** — 공통 에러 UI.

### 매핑 요약

| 우리 1단계 화면 | 원형 참고 | 성격 |
|---|---|---|
| 시작 | 타이틀.png | 부분 — 원형은 타이틀+서버선택 분리 |
| 캐릭터 선택 | card_* · emblem_* · bkg_* (4직업) | 직접 — 4직업 체계 원형 |
| 포스터 매칭 | 교환소3 (인용구+일치 결과) | 직접 |
| 단어주머니 | 교환소4·5, 문장제출2 | 직접 |
| 매니페스토 쓰기 | 문장제출2·3·4 | 직접 |
| 투표 | 투표소2·3 | 직접 |
| 결과 | 투표 결과 화면 ×3 | 직접 — 순위 + 그래프 2페이지 |
| (관리자) | 관리자화면 ×4 + 서버선택 | 신설 대상 — 원형 디자인 있음 |
| (교환소) | 교환소1·2 | v1 제외, 2단계 참고 |
| (전체Display·에러) | 각 1장 | 공용/공통 |
